# 🐉 Kali Easy Install – Professional .deb Package Manager

**Install and uninstall Debian packages on Kali Linux with a modern GUI. No terminal commands needed.**

![Python Version](https://img.shields.io/badge/python-3.13%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Platform](https://img.shields.io/badge/platform-Kali%20Linux-orange)

---

## ✨ Features

- 📦 **Install `.deb` packages** – Automatic dependency resolution
- 🗑️ **Uninstall applications** – Complete removal with cache cleanup
- 🔍 **Package browser** – Search installed apps (even with 1 character)
- 🖥️ **Live terminal output** – See exactly what `apt` is doing
- ⏱️ **Auto‑close timer** – Terminal closes 10 seconds after job finishes (or click "Keep Open")
- 📁 **View source code** – Built‑in code viewer
- 🔗 **GitHub integration** – One‑click access to developer profile
- 🎨 **Dark theme** – Futuristic, easy on the eyes

---

## 🛠️ Installation

### One‑click installer (recommended)

```bash
git clone https://github.com/mistaribaba/kali-easy-install.git
cd kali-easy-install
chmod +x install.sh
./install.sh
```
